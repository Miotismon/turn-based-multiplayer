# Example Steam Co-op Multiplayer Turnbased Exercise

For more info on this project check out my website: https://miotismon.github.io/research/godot-multiplayer/

### How I test steam multiplayer features locally:
I use [Sandboxie Plus](https://sandboxie-plus.com/) to run a second Steam client with another account and then run the project using
`<godot_console path> --path <project path> -d`
in Sandboxie.
This gives me a client with a seperate Steam account and a working command line debugger.
